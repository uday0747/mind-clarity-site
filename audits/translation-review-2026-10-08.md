# Translation review — 8 October 2026

The published language sets should not have been described as complete or fully reviewed. Route and metadata tests established that pages exist, not that translations preserve the English meaning.

## Scope and limits

Compared the structure of all 48 translated pages (12 each in Hindi, Spanish, French and Telugu) against the current English pages. The companion JSON records paragraph counts, disclosure counts and missing element IDs for every page before this correction. Paragraph counts are diagnostics, not linguistic scores: natural translation need not match paragraph counts exactly, and some missing IDs belong to optional sharing controls.

Read the detailed FAQ translation library in all four languages, examined the Telugu core FAQ, compared the philosophy sections and reviewed representative passages from the other page families. This is a coverage audit and an initial semantic review. It is **not** certification that every sentence on all 48 pages has received a complete editorial review. The existing Telugu AI article is a separate earlier translation and should also receive that review; its greater paragraph count does not prove accuracy.
